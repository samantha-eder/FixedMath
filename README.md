**FixedMath**是一个专为多端帧同步与确定性物理模拟打造的纯C#定点数学库

由于不同硬件架构与编译器对IEEE754浮点数标准的实现存在细微差异, 传统的`float`与`double`运算无法保证跨平台的逐位一致性. 本库基于64位有符号整型`long`构建完整的**Q32.32**定点数算术体系, 在运行时彻底剔除浮点运算, 从底层保障多端状态的绝对同步

## 核心架构
### 1.128位中间精度与防溢出算术体系
* **64x64 位拆分乘法与溢出检测** 在`FP.operator *`中将操作数拆分为高32位整数与低32位小数, 通过分配律展开合成, 并严格校验符号边界与高位溢出
* **128 位长除法** 在`FP.operator /`中将64位被除数左移构造为128位滑动窗口, 通过 64 轮二进制移位减法实现精确求商
* **128 位无损向量求模** 针对传统定点库在计算`Magnitude`时极易因平方运算($x^2 + y^2 + z^2$)溢出而崩溃的痛点, 本库在`FPVector2`与`FPVector3`中手写了128位无符号整数平方展开与带进位链累加, 并配合64轮128位逐位逼近开方算法, 确保只要最终模长在Q32.32范围内, 中间计算过程永不溢出

### 2.MSB缩放的向量归一化
* 在`FPVector2.Normalize`与`FPVector3.Normalize`中, 若直接除以模长, 极小向量会因下溢丧失方向精度, 极大向量则面临精度截断
* 本库通过二分移位快速检索各分量绝对值的最高有效位, 在求模前将向量等比例左移或右移对齐至第32位安全精度区间, 从数值分析层面消除了极端尺度下的归一化失真

### 3.Q2.62 超高精度无分支CORDIC三角引擎
* **内部计算** `Sin`、`Cos`、`Tan`、`Asin`、`Acos`、`Atan2` 内部统一调整为**Q2.62**格式, 保留62位小数精度, 执行33轮CORDIC向量旋转, 最终四舍五入回归Q32.32, 彻底消除低位截断累积误差
* **周期规约优化** 利用高精度($1/\pi$)常数将输入弧度映射为归一化周期标度, 通过`(scale + (1L << 61)) >> 62`单行位运算完成象限折叠与符号判定
* **防增益膨胀对齐** 在`Atan2Internal`中通过MSB检测将输入坐标等比缩放至第60位, 预留顶部3bit余量以吸收CORDIC迭代固有的模长膨胀($K \approx 1.64676$)
* **无分支预测** 迭代核心全面采用算术右移符号掩码`(value + mask) ^ mask`替代条件分支语句

### 4.高精度函数Sqrt / Log2 / Exp2 / Pow
* **平方根`Sqrt`** 采用逐位逼近法, 32轮提取整数与高位特征后, 追加16轮残差补零迭代以填满Q32.32全部小数精度
* **以2为底的对数`Log2`** 结合二分MSB整数定位与尾数归一化, (对齐至 $[1.0, 2.0)$)区间通过32轮平方逼近法逐位提取对数小数位, 进而导出自然对数`Ln`与常用对数`Log10`
* **指数与幂运算`Exp2` / `Pow`** 分离整数位移与小数残差, 利用预计算的Q2.62格式分数次幂查找表($2^{2^{-i}}$)配合64位扩展乘法合成高精度指数. `Pow`自动识别整数次幂并切换至快速幂算法

### 5.完备几何工具
* **完备的2D/3D与四元数几何** 内置`FPQuaternion`, 支持Unity标准的Z-X-Y欧拉角转换, 叉乘加速的向量旋转公式, 带最短路径纠偏与近零退化保护的`Slerp`球面插值以及随机数生成器`FPRandom`
